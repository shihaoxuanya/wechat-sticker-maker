# 上传指导与驳回修正

使用者自行登录微信表情开放平台。指导基于实际页面对应关系，不自动注册、登录、上传、勾选协议或提交。用户后来明确要求辅助操作时另按可用能力及其授权处理。

## 交付时必须说清楚

- 解压ZIP后使用 `submission` 下的对应素材；ZIP本身是交付容器，平台未明确支持时不要整包上传。
- 主图、缩略图编号01起连续、一一对应，数量和排序以实际当前页面为准。日常中文名称版便于辨认，但上传副本使用纯数字编号。
- 图标只选 `submission/assets/chat-icon.png`；封面和横幅选各自文件。带字主图、50px放大检查图、棋盘格预览图、高清母图均不是聊天图标上传文件。
- 文案表逐项列专辑名、介绍、版权署名及每款含义词。未确认的版权栏明确标注待填写，不拿角色名、工具名或“AI生成”自动替代权利人。
- 上传后检查平台预览：序号/含义词、透明底、裁切、封面、横幅和底部小图标；注意浏览器可能显示旧缩略图。以选中的文件名和页面最新预览共同核对。
- 若平台自动压缩，查看实际显示质量；必要时从母图按当前目标重导出，而非反复压缩已缩小文件。不要擅自改扩展名伪装格式。
- 保存草稿不等于提交；提交成功不等于审核通过。使用者完成提交后保留作品名称、提交时间和平台显示的状态，后续以平台结果为准。

## 驳回定位

| 驳回或问题 | 首先检查 | 修正方法 |
| --- | --- | --- |
| 聊天图标太小、去除文字/装饰 | 是否误传封面或带字缩图；50px原尺寸 | 独立正面头部，删额外字/星星/爱心，紧凑留白；不要仅加大画布 |
| 图标白边/锯齿/白底 | 真实alpha、深浅背景、白毛是否被误判 | 去外圈描边/背景，保留本体白色；从高清源图重新抗锯齿缩放 |
| 规格/体积不合格 | 实际类别与当前页面字段 | 更新有证据的profile及targets，重新导出对应副本 |
| 封面不合适 | 是否把仅头部图标当封面 | 按封面规则独立设计代表姿势 |
| 横幅文字/底色/变形 | 横幅独立规则和原图比例 | 重排横向画面，修正文案/背景，避免拉伸 |
| 表情显得小 | 角色/文字实际边界，不只看240画布 | 适度裁去空白、突出面部，保留完整手势和安全边距 |
| 错字、字不清楚 | 逐字核对与120px检查 | imagegen局部修字，保留手写风格并处理对比 |
| 内容/版权/肖像/AI声明 | 平台原话、素材来源、使用者提供的证明 | 先补齐事实或授权；不能换文件名、抹水印或假选类别规避 |

把驳回原文与目标文件写入 `revisions.json`（日期、原因、受影响文件、修正、复核）。不要推断未显示的驳回原因，不重做整套来掩盖一个图标问题。变更后重新构建、看图、检查和打包，向使用者指出应替换的确切文件。
